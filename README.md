# Laser Therapy In Lumbar Disc Herniation: Statistical Analaysis Report

R code and report for a randomized comparative study of high-intensity vs low-intensity laser therapy vs placebo in lumbar disc herniation.

## Contents
- Data cleaning and merging into one dataset with patient IDs for paired analysis.
- Baseline demographics table and nonparametric outcome analyses (median [Q1, Q3]).
- Within-group pre–post tests with correction (Wilcoxon signed-rank, Bonferroni).
- Between-group change-score tests with correction (Kruskal–Wallis + Bonferroni post hoc).
- Publication-ready tables and figures.
